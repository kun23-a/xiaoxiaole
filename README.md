# 🍬 消消乐 · 仿《开心消消乐》

HTML5 网页版三消，仿《开心消消乐》玩法。**双击 `index.html` 即可游玩**——无需服务器、无需联网、零依赖。

## 玩法特色

**特效棋子**
- 四连 → 条纹（清整行/列）；L/T 形五格 → 爆炸（3×3）；五连 → 彩虹（清全色）
- 点击特效直接触发（不耗步数）；两个特效交换出组合技：条纹+条纹=十字、条纹+爆炸=三行三列、爆炸+爆炸=5×5、彩虹+特效=清全色+范围

**障碍物与机制**
- 🧊 冰块：1-2 层，匹配破一层；🍮 果冻：目标格，消除即清除
- ⏱ 限时关卡：倒计时替代步数，目标完成即过关，剩余秒数转奖励分
- 🌀 传送门：入口/出口棋子互相传送（传送电路）
- 🦔 毛球怪：占据格子阻挡下落，相邻消除掉血、特效直击秒杀，定期蔓延，目标=清空全场

**目标体系**
- 分数 / 收集指定棋子 / 清除冰块 / 清除果冻 / 清空毛球，任意组合
- 目标完成即过关，剩余步数/秒数转奖励分；三星评价（达标 1★ / 1.3× 2★ / 1.8× 3★）
- 12 个手工关卡（蛊真人地域命名）+ 13 关起程序无限生成（限时/传送门/毛球/收集轮换），布局按关卡种子确定

## 模式

- 🎯 闯关模式（主玩法）；🧘 休闲模式（无尽解压）

## 运行

```powershell
# 方式一：直接双击 index.html
# 方式二：本地服务器（提供 http 链接）
node tools/serve.js     # → http://127.0.0.1:8756/
```
